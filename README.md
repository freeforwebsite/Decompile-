# Movie DB Bot Starter

This is a starter template for building a Telegram bot that indexes files from **your own Telegram channel** into MongoDB.

## Setup
1. Copy `.env.example` to `.env`.
2. Fill in your API_ID, API_HASH, BOT_TOKEN, MONGO_URI and CHANNEL_ID.
3. Install requirements.
4. Run `python main.py`.

Extend this project by adding handlers that index files from your own channel and search your own MongoDB database.
